← Enter → sind deine drei Tasten. Mit OK öffnest du das Menü, mit Links und Rechts wählst du eine Aktion.

Im Minispiel: Unter die fallende Beere bewegen und OK drücken, sobald sie im Fangbereich ist. Fünf Versuche pro Runde.

Über Pocket Pet

Die Spielregeln laufen in C++. Der Browser zeigt das Display und leitet drei Tasten weiter. Display und ESP32-Treiber folgen nach Auswahl der Hardware.

Alles bleibt auf diesem Rechner. Keine Konten, keine Analyse-Dienste, keine externen Schriftarten. Der Spielstand liegt im lokalen saves-Ordner. Das Programm läuft weiter, solange der lokale Server läuft.

Pokémon-Namen gehören ihren jeweiligen Rechteinhabern. Dieses Fanprojekt ist nicht offiziell. Die Grafiken sind selbst gezeichnete Platzhalter.
